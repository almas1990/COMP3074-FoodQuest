# Food Quest UI Prototype

Food Quest is a COMP3074 Mobile Application Development I UI prototype for team P23.
It turns discovering local food places into a scavenger-hunt style mobile game.

## Prototype Features

- Splash / Home screen
- Quest List screen with search and tag filters
- Quest Detail screen
- Add / Edit Quest screen
- Map / Directions mock screen
- Achievements / points screen
- About / Team screen
- Working interactions for:
  - filtering/searching quests
  - opening quest details
  - marking a quest complete
  - updating points
  - adding a new quest

## How To Run

1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select an Android emulator or connected Android device.
4. Run the `app` configuration.

The prototype is intentionally local-only. Google Maps and persistent Room storage are represented in the UI and planned for the functional prototype.
